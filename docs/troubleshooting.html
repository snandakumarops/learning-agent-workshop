Troubleshooting

Iterative development is normal — even experienced developers encounter errors. Here are common issues and how to resolve them.

General Agentforce Vibes Issues

Agentforce Vibes is unresponsive

  • Wait a moment — Agentforce Vibes may be "thinking" through complex requirements.
  • Click Try Again if the response seems stuck.
  • Start a new task if the current conversation isn't progressing.
  • Check the terminal for error messages.
  • Ask a facilitator if the problem persists.

MCP and Connection Issues

"Cannot find default-target org" error

This means the MCP server lost its connection to your org. To fix it:

  • Open the MCP Servers panel in the Let's Vibe sidebar.
  • Toggle the Salesforce DX server off (red indicator).
  • Wait a few seconds, then toggle it back on (yellow, then green indicator).
  • The MCP server acts as the bridge between Agentforce Vibes and the Salesforce CLI — toggling it re-establishes the connection.
  • As a fallback, open the terminal and run sf org list to verify your default org is set.

Build Issues

Planning phase is taking a long time

The planning phase can take 2–3 minutes. This is normal — Agentforce Vibes is analyzing your org metadata and determining the best approach.

Code generation errors

  • Code generation errors are expected — even AI-written code needs iteration.
  • Agentforce Vibes often self-corrects automatically. Watch for it to detect and fix issues on its own.
  • If it doesn't self-correct, provide the full error message including any stack traces when starting a new task.

Deployment Issues

Deployment failed

  • Read the error message carefully — it usually tells you exactly what went wrong.
  • Copy the error message and start a new task asking Agentforce Vibes to fix the issue.
  • Common causes: missing dependencies, syntax errors, or org connection problems.
  • If your LWC references an Apex class, make sure the Apex is deployed before the LWC.

Lightning Preview and Testing Issues

App looks different than expected

This is normal. Generative AI incorporates randomness, so your app's appearance may vary slightly from the screenshots in this guide. As long as the leaderboard widget displays the correct data, it's working correctly.

UI elements are not functional

Open the browser DevTools (Cmd + Option + I on Mac, Ctrl + Shift + I on Windows) and check the Console tab for JavaScript errors.

Changes not showing up

  • Try clearing your browser cache or doing a hard refresh (Cmd + Shift + R / Ctrl + Shift + R).
  • Lightning preview may have port conflicts — check the terminal for any port-related errors.
General advice

When in doubt: check the terminal output, review the agent's responses carefully, and don't hesitate to start a fresh task. If you're stuck, raise your hand and a facilitator will help.
