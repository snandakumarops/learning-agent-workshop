Setup

🕓 7 minutes

Complete these steps before the workshop session so you're ready to go when we start.

Sign up for your workshop org

1 Open the sign-up URL

Navigate to the sign-up URL provided by your facilitator. Enter the event code and your email address — you'll receive org credentials by email. Click the link to open the org directly.

Save your credentials

Write down your username and password — you'll need them throughout both parts of the workshop.

2 Confirm you see the app

In your production org, click the App Launcher (the grid icon in the top left) and search for Learning Management. You should see the Connected Executive Education dashboard with a Course Enrollments table.

Log into your sandbox

3 Navigate to Sandboxes

In your production org, click the gear icon in the top right and select Setup. In the Quick Find box on the left, type sandbox and click Sandboxes under Environments.

4 Log into the fullcopy sandbox

You will see two sandboxes listed. Use the fullcopy sandbox — click Log In next to it. If prompted to register your phone number, you can skip that step.

If you need to log in again later, go to test.salesforce.com. The username is your production username with .fullcopy appended (e.g. user@example.com.fullcopy) and the password is orgfarm1234.

Enable Change Management

5 Turn on Org-to-Org Metadata Deployment

Inside the fullcopy sandbox, go to Setup → search for change in Quick Find → Change Management under Development. Toggle on Org-to-Org Metadata Deployment (Beta).

This enables metadata deployment between your sandbox and production — used in both Part 1 and Part 2.

Activate MCP Servers

MCP (Model Context Protocol) servers connect Agentforce Vibes to your org's capabilities. You need to activate two servers — they're used in the AI-Accelerated path (Part 2) of the workshop.

6 Navigate to MCP Servers

In your sandbox, go to Setup → search for mcp ser in Quick Find → MCP Servers under Integrations > API Catalog. You'll see a list of available servers, all with status Inactive.

7 Activate salesforce-api-context

Click salesforce-api-context from the list, then click Activate. This server provides Agentforce Vibes with Salesforce API context so it can generate code that works with your org's specific configuration.

8 Activate metadata-experts

Go back to the MCP Servers list and click metadata-experts, then click Activate. This server allows Agentforce Vibes to discover and inspect your org's metadata — objects, fields, relationships, and configurations.

Having trouble?

If you can't log in or don't see the Learning Management app, raise your hand at the start of the workshop and a facilitator will help you get set up.

Once you can see the app in your sandbox and the MCP servers are active, you're all set.
