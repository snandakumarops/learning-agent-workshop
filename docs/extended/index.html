Agent & App Development Workshop

🕓 ~4 hours

In this workshop, you'll get hands-on with real development scenarios across different ways of working and building on the Salesforce Platform — all through the same governed, sandbox-first pipeline to production.

The scenario

You're a developer on the team that manages the Connected Executive Education app. Two requests have come in from the business today:

  1. Add a new Deferred enrollment status — students pausing to join a future cohort are being incorrectly marked as Withdrawn.
  2. Add a Top Learners Leaderboard widget to the dashboard so program directors can see high performers at a glance.

The development paths

Development isn't one-size-fits-all — you choose how you work and how you develop, and every team is a blend of the two.

How you work

Solo

Work independently for fast, isolated execution with minimal overhead.

Coordinated

Collaborate across teams to synchronize parallel changes.

How you develop

Human Driven

Use code or visual tools to build a solution.

Agent Driven

Agents act on natural language intent to build solutions.

This workshop focuses on the Solo, Coordinated, and Agent Driven paths.

Before the session

  1. PRE Setup — Sign up for your workshop org and log into the fullcopy sandbox Before the session

Workshop agenda

The workshop is organized into paths. Everyone starts with the Application Overview, then works through the paths relevant to them.

Application Overview
  1. 1 Inspect the App — Tour the Learning Management app: explore Courses, Students, and Enrollments, and see the dashboard you'll be enhancing 2 min
Solo
  1. 1 Add the Deferred Status — Add a new picklist value to the Enrollment Status field directly in Setup, no code required 10 min
  2. 2 Promote to Production — Use DX Inspector to review the diff and promote the field change from sandbox to production 10 min
Coordinated
  1. 1 Coordinated Development — See how teams operate at scale with DevOps Center: source-tracked development, built-in change management, and release pipelines 5 min
Agent Driven
  1. 1 Agentforce Vibes Walkthrough — Launch Agentforce Vibes and get oriented with MCP servers, skills, rules, and the Metadata Explorer 8 min
  2. 2 Build the Leaderboard — Write a natural language prompt and let Agentforce Vibes generate the Apex and LWC code for the Top Learners widget 7 min
  3. 3 Verify — Open your sandbox and confirm the Top Learners widget appears on the dashboard 2 min
  4. 4 Promote to Production — Open DX Inspector to review changed files, then promote from sandbox to production 5 min
