Agent & App Development Workshop

🕓 ~2 hours

In this workshop, you'll walk two real development scenarios — a quick metadata change made entirely in the UI, and a full feature build using Agentforce Vibes. Both go through the same governed, sandbox-first pipeline to production.

The scenario

You're a developer on the team that manages the Connected Executive Education app. Two requests have come in from the business today:

  1. Add a new Deferred enrollment status — students pausing to join a future cohort are being incorrectly marked as Withdrawn.
  2. Add a Top Learners Leaderboard widget to the dashboard so program directors can see high performers at a glance.

The three development paths

There are 3 agent & application development paths. This workshop covers two of them:

The Solo Admin Path

For solo admins and small hybrid teams making surgical updates — UI copy tweaks, field changes, and quick config fixes.

The Team Path

For small hybrid teams, multiple teams, and enterprise teams building large-scale features. Source-tracked development with built-in change management and release pipelines.

The AI-Accelerated Path

For multiple teams and enterprise teams building complex, high-quality features using natural language. AI-accelerated development workflows.

Workshop agenda

Use Case 1 — Solo Admin Path
  1. 1 Add the Deferred Status — Add a new picklist value to the Enrollment Status field directly in Setup, no code required 12 min
  2. 2 Promote to Production — Use DX Inspector to review the diff and promote the field change from sandbox to production 10 min
Use Case 2 — AI-Accelerated Path
  1. 3 Inspect the App — Tour the Learning Management app: explore Courses, Students, and Enrollments, and see the dashboard you'll be enhancing 2 min
  2. 4 Agentforce Vibes Walkthrough — Launch Agentforce Vibes and get oriented with MCP servers, skills, rules, and the Metadata Explorer 8 min
  3. 5 Build the Leaderboard — Write a natural language prompt and let Agentforce Vibes generate the Apex and LWC code for the Top Learners widget 7 min
  4. 6 Verify — Open your sandbox and confirm the Top Learners widget appears on the dashboard 5 min
  5. 7 Promote to Production — Open DX Inspector to review changed files, then promote from sandbox to production 5 min
