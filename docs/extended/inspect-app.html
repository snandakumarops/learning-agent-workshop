Inspect the App

🕓 2 minutes

The Learning Management app is a fully configured minimal custom application that Connected Executive Education (CEE) built on the Salesforce Platform. Before you start building with Agentforce Vibes, take a brief tour of the core building blocks.

Open the app

1 Navigate to the Learning Management app

If you haven't already, in your sandbox, click the App Launcher (the grid icon in the top left) and search for Learning Management. Click to open it.

You should see the Connected Executive Education dashboard with a Course Enrollments table.

Explore the data

The app is built on three custom objects that work together. Click each tab in the navigation bar to explore the data. You may need to switch the list view to All to see all the records.

2 Courses

The Courses object stores all offerings in CEE's executive education catalog. Each record has a Course ID (e.g. COURSE-0012) and a Title (e.g. "Executive Leadership Essentials").

Click the Courses tab to browse the catalog. There are 8 courses available.

3 Students

The Students object captures learner profiles for individuals enrolled in CEE's executive programs. Each record has a Student ID (e.g. STU-0018), Email, First Name, and Last Name.

Click the Students tab to see enrolled learners. There are 12 students.

4 Enrollments

The Enrollments object connects students to their courses and tracks progress. Each record has an Enrollment ID (e.g. ENR-0035), a lookup to Course, Enrollment Date, Status, and a lookup to Student.

Click the Enrollments tab to see how students are progressing. There are 23 enrollments.

The dashboard

5 Return to the dashboard

Click the Learning Management tab to return to the main dashboard. This is the page you'll be enhancing — by the end of the workshop, you'll have added a Top Learners Leaderboard widget right here.

Save this screenshot

Right-click the image above and save it to your computer. You'll use this screenshot later to guide Agentforce Vibes on where to position the new widget on the dashboard.

What you just learned

The app has three objects — Courses, Students, and Enrollments — and a dashboard that aggregates enrollment data. Agentforce Vibes will use this same metadata when you prompt it to build the leaderboard.
