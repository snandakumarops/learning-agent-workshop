Build the Leaderboard

🕓 7 minutes

Now it's time to build. You'll give Agentforce Vibes a natural language prompt along with the dashboard screenshot you saved earlier, and it will retrieve the existing code, generate new components, and create tests for you.

Submit the prompt

1 Attach the dashboard screenshot and submit the prompt

First, find the dashboard screenshot you saved in Step 1 (the one with the orange arrow) in Finder (Mac) or File Explorer (Windows) and copy it (Cmd + C on Mac, Ctrl + C on Windows). Then click into the prompt input in Agentforce Vibes and paste it (Cmd + V / Ctrl + V). You should see the image attached to the conversation. Then type the following prompt:

Retrieve the existing learningManagementDashboard LWC component and the LearningManagementController Apex class from my org. Then add a "Top Learners Leaderboard" widget to it. It should show the top 5 students ranked by average progress across all their enrollments. Display the student name, number of courses enrolled, and average progress with a progress bar. Place the widget where marked on the attached screenshot. Use the existing Enrollment__c and Student__c objects. Create any needed Apex methods in the existing LearningManagementController.

Watch it build

2 Agentforce generates the code

Agentforce Vibes first retrieves the existing LWC and Apex controller from your org, then reads your org metadata through the MCP servers and starts building. Notice how it identifies issues along the way and fixes them automatically. You'll see it:

  • Retrieve the existing learningManagementDashboard LWC and LearningManagementController Apex class
  • Update the Apex controller — add a new method to query top learners
  • Update the LWC — add the leaderboard widget to the existing dashboard HTML, JS, and CSS
Approve requests to proceed

Agentforce Vibes will ask for permission before editing or creating each file. You can approve each request to let it proceed.

3 It even creates tests

Agentforce Vibes doesn't stop at the feature code. It also generates a test class — LearningManagementControllerTest.cls — with comprehensive test coverage for the new Apex method, including assertions for ranking, data validation, and edge cases.

4 Deploy to sandbox

Once all tasks are complete, Agentforce Vibes will deploy the changes back to your org. You'll see it use the deploy_metadata tool on the Salesforce DX MCP server. Approve the request to proceed.

What just happened

From a single natural language prompt and a screenshot, Agentforce Vibes retrieved the existing code, updated the Apex controller and LWC component, created a test class, and deployed everything — all grounded in your org's actual metadata.
