Agent & App Development Workshop

🕓 40 minutes

In this workshop, you'll use Agentforce Vibes to build a Top Learners Leaderboard widget on a Learning Management dashboard — using natural language. You'll experience the AI-accelerated path of the Salesforce Agent & Application Development process: Build, Test, and Deploy.

The scenario

You're a developer on a team that manages a Connected Executive Education app. The app already has a dashboard showing course enrollments. Your task: add a Top Learners Leaderboard widget to that dashboard using Agentforce Vibes.

The three development paths

There are 3 agent & application development paths. This workshop focuses on the AI-Accelerated Team path:

The Solo Admin Path

For solo admins and small hybrid teams making surgical updates — UI copy tweaks, field changes, and quick config fixes.

The Team Path

For small hybrid teams, multiple teams, and enterprise teams building large-scale features. Source-tracked development with built-in change management and release pipelines.

The AI-Accelerated Path (this workshop)

For multiple teams and enterprise teams building complex, high-quality features using natural language. AI-accelerated development workflows.

What is Agentforce Vibes?

Agentforce Vibes is an AI-powered development environment inside Salesforce. You describe what you want in plain English, and it writes the code, helps you test it, and deploys it. Think of it as enterprise vibe coding — AI-assisted development with governance, security, and scalability built in.

Before the session

  1. PRE Setup — Sign up for your workshop org, check your email for credentials, and verify you can log in Before the session

Workshop agenda

  1. 1 Inspect the App — Tour the Learning Management app: explore Courses, Students, and Enrollments, and see the dashboard you'll be enhancing 2 min
  2. 2 Agentforce Vibes Walkthrough — Launch Agentforce Vibes from the App Launcher and get oriented with the key building blocks: MCP servers, skills, rules, and the Metadata Explorer 8 min
  3. 3 Build the Leaderboard — Write a natural language prompt describing the Top Learners Leaderboard widget and let Agentforce Vibes generate the Apex and LWC code for you 7 min
  4. 4 Verify — Open your sandbox org and confirm the Top Learners Leaderboard widget appears on the dashboard 5 min
  5. 5 Promote to Production — Open DX Inspector to review changed files, then promote from sandbox to production 5 min
