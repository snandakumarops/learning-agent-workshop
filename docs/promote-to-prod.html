Promote to Production

🕓 5 minutes

Your leaderboard is live in the sandbox. Now use Change Management to promote the changes from sandbox to production — no CLI, no package.xml, just point and click.

Open Change Management

1 Open Change Management

In your sandbox, click the Sandbox badge in the top-left corner to open the DX Inspector. Since this is a Full sandbox, you'll need to manually add the metadata you want to deploy.

Add metadata

2 Add the LWC component

Click Add Metadata (the + icon). Set the Metadata Type to LightningComponentBundle, search for learning, select learningManagementDashboard, then click Add.

3 Add the Apex class

Click Add Metadata again. Set the Metadata Type to ApexClass, find and select LearningManagementController, then click Add.

4 Review the metadata list

You should now see 2 items in the Change Management list:

  • LearningManagementController — ApexClass
  • learningManagementDashboard — LightningComponentBundle

Connect to production

5 Connect to production

Click Deploy Options and select your items. In the Deploy Changes dialog, click New Environment. Enter production as the Environment Name, select Production org as the type, and click Connect. You'll be redirected to authenticate — log in with your production org credentials and click Allow.

After authorization, go back to the Deploy Changes dialog and switch to the Existing Environment tab. Select the production org you just connected.

Deploy

6 Preview and deploy

After authorization, you'll see the Deploy Changes preview showing the Source Org (your sandbox) and Target Org (production), along with the 2 metadata items. Click Deploy.

7 Verify in production

Wait a few minutes for the deployment to complete, then open your production org and navigate to the Learning Management app to verify the Top Learners Leaderboard is live.

You did it

You just went from a natural language prompt to a production deployment — building, testing, and promoting a new feature using Agentforce Vibes and Change Management. No CLI, no package.xml, no manual code.
